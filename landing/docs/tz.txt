ТЗ на лендинг Preggo в стиле Apple scroll-storytelling

1. Общая задача

Нужно сделать премиальный, очень дорогой по ощущению, cinematic landing page для Preggo — AI-платформы для безопасной беременности.

Это не обычный сайт с блоками.
Это должен быть Apple-style scroll experience, где пользователь не просто читает сайт, а проходит через историю:

uncertainty → interpretation → clarity → control

Сайт должен продавать не “милое приложение для беременных”, а ощущение:
	•	уверенности
	•	контроля
	•	спокойствия
	•	технологичности
	•	медицинской серьезности
	•	premium digital health experience

Preggo по своей сути — это не контентное pregnancy app, а safety-first system с continuous monitoring, AI risk logic, lab/document scanner, doctor-facing reports и alerts. Это прямо следует из нашей продуктовой логики и материалов по Stage 1–2.  ￼  ￼

⸻

2. Референс и ощущение

Основной референс

Сайт должен ощущаться почти как Apple product page:
	•	большой cinematic hero
	•	очень сильный фокус на одном главном устройстве/объекте в центре
	•	длинный скролл с постепенным раскрытием продукта
	•	крупная типографика
	•	много воздуха
	•	очень дорогие transitions
	•	минимум визуального шума
	•	одна мысль за экран
	•	секции работают как сцены

У Apple сейчас особенно сильны такие приемы:
	•	выразительный, “delightful” визуальный стиль с полупрозрачностью и акцентом на фокусе на контенте.  ￼
	•	плавные collapse / zoom transitions, когда крупный hero уменьшается в компактную навигацию или следующий блок.  ￼
	•	immersive-подача продукта как отдельного experience, а не просто списка характеристик.  ￼

Что должно ощущаться по вайбу

Смесь из:
	•	Apple
	•	Apple Health
	•	Oura
	•	Whoop
	•	premium wellness / digital health brand
	•	немного sci-fi, но мягко
	•	без дешевого “cute pregnancy app” вайба

5. Целевая визуальная стратегия

Базовый визуальный принцип

На первом экране и на протяжении почти всего сайта главным героем остается iPhone mockup с интерфейсом Preggo.

Идея:
	•	телефон — центр сцены
	•	вокруг него живут данные, свет, сигналы, анимации
	•	по мере скролла телефон:
	•	увеличивается
	•	приближается
	•	UI раскрывается
	•	уходит на второй план
	•	возвращается в финале

Важный принцип

Сайт должен быть не “много карточек и текста”, а sequenced visual storytelling.

6. Структура страницы

Секция 1. Hero / Opening Scene

Что должно быть
	•	fullscreen hero
	•	светлый премиальный градиентный фон
	•	по центру iPhone mockup
	•	в телефоне — UI Preggo с heartbeat / risk alert / clean dashboard
	•	сверху очень минимальная навигация

Контент

Большой headline:
Know earlier. Worry less.

Подзаголовок:
Preggo uses continuous AI monitoring, risk detection, and doctor-ready insights to help you understand what’s happening with your body.

Primary CTA:
Get early access

Secondary supporting microcopy:
Takes 30 seconds to start

Анимация

При первом экране:
	•	телефон плавно появляется через fade + slight scale
	•	фон живой, но очень subtle
	•	вокруг телефона появляются мягкие flowing light trails
	•	в самом UI есть легкое micro-motion: heartbeat line, gentle pulse, small UI glow
	•	headline может появляться по строкам или по словам

Ощущение

Сразу должно быть понятно:
это не контентный лендинг, это premium product reveal

⸻

Секция 2. Uncertainty / Pain Scene

Смысл

Показать эмоциональную боль беременности:
	•	тревога
	•	хаос
	•	много данных
	•	мало ясности

Визуал

При скролле iPhone слегка zoom-in, потом вокруг него или вместо него появляются слои:
	•	fragmented search queries
	•	scattered symptom notes
	•	blurred lab results
	•	floating question fragments

Примеры текста в воздухе:
	•	Is this normal?
	•	Should I worry?
	•	Am I missing something?
	•	What does this result mean?

Контент

Headline:
Pregnancy shouldn’t feel like guessing.

Support text:
Between doctor visits, most women are left with questions, scattered data, and no clear interpretation.

Анимация
	•	появляется controlled chaos
	•	элементы не должны быть ugly; это красивый, premium chaos
	•	floating cards, blurred panels, layered motion
	•	можно добавить slight parallax
	•	потом весь хаос буквально стягивается в центр и собирается в систему

⸻

Секция 3. Transition to Clarity

Смысл

Ключевой момент transformation:
хаос превращается в одну ясную картину

Контент

Headline:
From scattered signals to one clear picture.

Визуал
	•	fragmented UI fragments собираются в clean central dashboard
	•	document snippets, graph lines, symptom data, wearable metrics сливаются в одну панель
	•	фон становится чище, светлее, спокойнее

Анимация

Это должна быть одна из самых красивых сцен:
	•	particles / lines / cards converging
	•	morph animation
	•	light trails gather into interface
	•	blur → sharp focus transition

11. Анимации: обязательные

Scroll-driven

Нужна полноценная scroll-based animation architecture.

Обязательные эффекты
	1.	hero fade + scale in
	2.	phone zoom in on scroll
	3.	parallax layers
	4.	blur-to-focus transitions
	5.	UI cards entering with stagger
	6.	floating light trails
	7.	section pinning for at least hero + feature reveal
	8.	document scanning animation
	9.	morph / converge transition from chaos to clarity
	10.	final CTA cinematic fade

Motion principles
	•	smooth
	•	expensive
	•	restrained
	•	no cheap bouncy motion
	•	no gimmicky overanimation
	•	motion should feel engineered, not playful

12. Технический стек и библиотеки

Предпочтительный стек
	•	Next.js
	•	React
	•	TypeScript
	•	Tailwind CSS

Для анимаций

Использовать по максимуму мощные инструменты:
	•	GSAP
	•	ScrollTrigger
	•	Framer Motion
	•	Lenis для smooth scroll
	•	React Three Fiber при необходимости для одного hero-level 3D/lighting effect
	•	Spline можно использовать, если удобно для 3D scene / phone presentation
	•	Motion One можно как вспомогательное, но основной стек лучше GSAP + Framer Motion
	•	Lottie только если очень нужно для отдельных controlled animations, но лучше избегать ощущения шаблонности

Рекомендованный подход
	•	GSAP + ScrollTrigger = основной scroll storytelling
	•	Framer Motion = micro-interactions / section reveals
	•	Lenis = smooth premium scrolling
	•	Tailwind = layout speed
	•	optional R3F = subtle 3D phone/parallax light scene

13. UX-принципы

Главное
	•	сайт должен быть визуально мощным, но понятным
	•	пользователь не должен теряться
	•	каждая секция = одна мысль
	•	скролл должен вести за руку
	•	не перегружать десятью карточками сразу
	•	весь опыт должен ощущаться clean and inevitable

Мобильная адаптация

Важно:
	•	desktop = полный cinematic experience
	•	mobile = упрощенная, но тоже дорогая версия
	•	не ломать scroll storytelling на телефоне
	•	на mobile можно:
	•	уменьшить количество pinned scenes
	•	упростить parallax
	•	оставить key transitions
